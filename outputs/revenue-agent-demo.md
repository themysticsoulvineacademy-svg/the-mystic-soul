## The Unique Mechanism

**"The Revenue Agent Stack"** — four specialist agents that hand work to each other in a fixed order so no single step gets skipped or done half-attention:

`market-signal-researcher → offer-architect → content-angle-strategist → conversion-system-builder`

The believability comes from *separation of concerns*: each agent has one job, can't do the others' jobs (the researcher is even blocked from writing files), and the coordinator forces every output to connect back to revenue — so the system structurally can't drift into generic "AI tips" content the way a single chat prompt does.

**Proof Requirements (what must be shown on screen):**
- The actual `.claude/agents/*.md` files, briefly, so viewers see this is real config, not a script.
- A live run producing a real, specific output (not a mockup) — ideally on FuturIQ's own idea, on screen, unedited reaction included.
- The final generated brief file, scrolled through, showing it's a complete, usable document.

**Objection Map:**
| Objection | Response in video |
|---|---|
| "I don't code" | Show that agents are just markdown files with plain instructions — zero code shown. |
| "This is just prompt engineering" | Show the handoff structure and file-based memory — a single prompt can't do role separation or persist between steps. |
| "AI changes too fast, this'll be outdated" | Frame it as a reusable *process*, not a tool — the agents can be swapped, the pipeline stays. |
| "I don't have an audience yet" | Note the system produces the offer *and* the content plan simultaneously — it's built for zero-to-one, not scale. |

## What the Creator Must Show On Screen to Be Credible

- Real terminal/file output, not a mockup or slide recreation.
- The actual agent definition files, even briefly — proves this is a real config, not a bit.
- An unedited or lightly-edited reaction to the generated output — polish here reads as fake.
- The finished brief file as a real, scrollable document, not a summary slide.

## What to Remove Because It Feels Generic

- Any "here are 5 AI tools you should try" segment — this is the exact genre the video needs to feel opposite of.
- Explaining what a "prompt" or "LLM" is — this audience already knows; over-explaining basics undercuts the "advanced but usable" positioning.
- A long personal intro before the hook — the brief specifies direct, no-fluff voice; the build should start almost immediately.
- Generic urgency language ("AI is changing everything") without a specific, demonstrated mechanism to back it up.
